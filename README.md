# AssemblyFlow

Front-end local para organizar, editar, visualizar e imprimir documentos de assembleia. O workbook de referência é usado somente durante o desenvolvimento; o aplicativo funciona sem Excel e sem conexão com a internet.

This is an React **Rsbuild project**

#### - To up and run follow steps bellow

**Access Project folder and**

## Setup

Install the dependencies:

```sh
    $ pnpm install
```

## Get started

Start the dev server, and the app will be available at [http://localhost:3000](http://localhost:3000).

```sh
    $ pnpm dev
```

Build the app for production:

```sh
    $ pnpm build
```

Preview the production build locally:

```sh
    $ pnpm preview
```

- To Test E2E, install cypress (only first time):
```sh
    $ npx cypress install
```  

- Run Test:
```sh
    $ pnpm test
```  

- Run Documentation:
```sh
    $ pnpm storybook
```
